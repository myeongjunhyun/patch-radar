# 🛰️ Patch Radar

> 보안 공지와 CVE를 RAG로 검색해 출처와 함께 답하고, 내 자산 기준 패치 우선순위를 알려주는 챗봇

## 📌 프로젝트 소개

매년 수만 건의 취약점(CVE)이 새로 공개되지만, 보안 담당자가 이를 모두 읽고 우리 조직에 해당하는 것을 찾아내기는 어렵습니다.

**Patch Radar**는 KISA 보호나라 보안공지, NVD의 CVE 정보, CISA KEV(실제 악용 취약점) 목록을 수집하고, 생성형 AI(RAG)를 활용해 다음 질문에 답합니다.

- "최근 Apache 관련 취약점 알려줘"
- "이번 주 긴급 보안 공지 요약해줘"
- "우리 서버 환경에서 지금 가장 먼저 패치해야 할 건 뭐야?"

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 보안 이슈 질의응답 | 질문과 관련된 보안공지·CVE를 검색해 요약하고 **출처 링크를 함께 제공** |
| 주간 보안 브리핑 | 최근 7일간의 보안 공지를 한 번에 요약 |
| 자산 기반 우선순위 | 사용 중인 소프트웨어 목록을 입력하면 해당 취약점만 골라 패치 우선순위 제시 |

### 우선순위 산정 방식

환각(hallucination)을 방지하기 위해 **우선순위 점수는 규칙 기반으로 계산**하고, LLM은 결과를 설명하는 역할만 맡습니다.

1. **CISA KEV 등재 여부**: 실제 공격에 악용 중인 취약점 최우선
2. **CVSS 점수**: 위험도가 높을수록 우선
3. **자산 일치 여부**: 등록한 제품·버전에 해당하는지 확인

## 🗂️ 데이터 소스

- [KISA 보호나라 보안공지](https://www.boho.or.kr): 국내 보안 공지 (한국어)
- [NVD API](https://nvd.nist.gov/developers): CVE 상세 정보 및 CVSS 점수
- [CISA KEV Catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog): 실제 악용 중인 취약점 목록

## 🛠️ 기술 스택

- **Language**: Python
- **LLM Framework**: LangChain
- **Vector DB**: Chroma
- **Embedding**: 다국어 임베딩 모델 (예: bge-m3)
- **UI**: Streamlit

## 🏗️ 시스템 구조

```
[데이터 수집]            [전처리·임베딩]        [검색·답변]           [UI]
보호나라 공지  ─┐
NVD CVE       ─┼─▶  청킹 → 임베딩 → Chroma ─▶ RAG 검색 + LLM ─▶ Streamlit
CISA KEV      ─┘                              우선순위 계산
```
